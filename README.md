# Cognifyz Task 1 - Basic HTML

## About the Project
This project is created as part of my Front-End Development Internship at Cognifyz Technologies.

The objective of this task is to learn the basics of HTML and create a simple webpage.

## Features
- Basic HTML document structure
- Main heading and subheading
- Paragraphs with introductory text
- Image displayed using the HTML `img` tag
- Alternative text using the `alt` attribute

## Technologies Used
- HTML5

## Project Structure
```text
Cognifyz-Task-1-Basic-HTML/
└── index.html
```

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser.

## Learning Outcome
I learned how to create a basic HTML webpage, add headings and paragraphs, and insert an image.
